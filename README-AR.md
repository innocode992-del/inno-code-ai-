# Inno Code — تطوير آمن للمساعد الحالي

هذه النسخة تحافظ على واجهة Inno Code ونظام المحادثات المحفوظ محليًا، وتضيف أدوات المتصفح والمرفقات مع الإبقاء على Gemini API في Vercel.

## المزايا في هذه النسخة

- محادثات سابقة ومحادثة جديدة، مع استمرار حفظ السجل داخل Local Storage في المتصفح.
- الوضع الفاتح والداكن والتصميم المتجاوب.
- زر ميكروفون يحوّل الكلام إلى نص داخل صندوق الكتابة. يجب مراجعة النص والضغط على إرسال بنفسك. يعتمد على Web Speech API، ودعمه يختلف حسب المتصفح واللغة.
- زر قراءة لكل رد من Inno Code باستخدام SpeechSynthesis المدمجة في المتصفح، مع إيقاف مؤقت ومتابعة وإيقاف.
- قائمة (+) لرفع الصور وPDF والملفات النصية والكود المدعومة.
- تحليل الصور وPDF عبر Gemini multimodal، وإرسال محتوى الملفات النصية كجزء من رسالة المستخدم.
- أدوات تصدير للردود: TXT وDOCX، وفتح نافذة الطباعة لحفظ PDF. كتل الكود يمكن تنزيلها بامتداداتها، ويمكن جمعها في ZIP.
- استخدام شعار Inno Code المرفق كأيقونة داخل الواجهة.

## تثبيت Inno Code على الموبايل كتطبيق

أُضيف دعم PWA حتى يمكن إضافة Inno Code إلى الشاشة الرئيسية وفتحه في نافذة مستقلة، من غير إنشاء APK أو تطبيق متجر منفصل.

- يجب فتح الموقع من رابط HTTPS (رابط Vercel يوفر HTTPS عادةً).
- Android: افتح الموقع في Chrome، ثم استخدم زر «تثبيت التطبيق» داخل إعدادات Inno Code أو قائمة Chrome > «تثبيت التطبيق» / «إضافة إلى الشاشة الرئيسية».
- iPhone/iPad: افتح الموقع في Safari، اضغط زر المشاركة، ثم «إضافة إلى الشاشة الرئيسية» واضغط «إضافة». زر التثبيت داخل الإعدادات يعرض هذه الخطوات عند عدم توفر نافذة تثبيت تلقائية.
- يتم تخزين واجهة التطبيق والملفات الأساسية مؤقتًا لتسريع الفتح. إرسال الرسائل ورفع الملفات وميزات Gemini تظل محتاجة اتصال إنترنت؛ التطبيق ليس نسخة تعمل بالذكاء الاصطناعي دون إنترنت.
- أيقونة الشاشة الرئيسية مأخوذة من شعار Inno Code المرفق.

## الملفات الأساسية

- `index.html`: هيكل الواجهة.
- `assets/app.js`: سجل المحادثات، الميكروفون، قراءة الردود، المرفقات والتنزيلات.
- `assets/styles.css`: مظهر الواجهة ودعم الأزرار الجديدة.
- `assets/inno-mark.jpeg`: علامة Inno Code المرفقة.
- `api/chat.mjs`: اتصال Gemini ومعالجة المرفقات على الخادم.
- `api/status.mjs`: فحص وجود المفتاح دون كشفه.

## حدود المرفقات الحالية

- حتى 4 ملفات في الرسالة الواحدة.
- إجمالي حجم الملفات لا يتجاوز 2.5 MB.
- الصور المقبولة: JPEG وPNG وWEBP وGIF.
- المستند: PDF.
- الملفات النصية: TXT وMD وCSV وJSON وHTML وCSS وJS وMJS وTS وXML وLOG.
- الحد الأقصى للملف النصي الواحد 500 KB.
- لا يتم حفظ محتوى الملفات الثنائية في سجل المتصفح؛ يُحفظ اسم المرفق في المحادثة فقط. عند فتح المحادثة لاحقًا، أعد إرفاق الملف إن احتجت تحليله مرة أخرى.
- ملفات DOCX ليست ضمن صيغ الإدخال في هذا التحديث؛ حوّلها إلى PDF أو نص قبل رفعها.

## إعداد Vercel

تأكد من استخدام المتغير السري الحالي:

- `GEMINI_API_KEY`: مفتاح Gemini الحالي.
- `GEMINI_MODEL`: اختياري. إذا كان موجودًا في مشروعك، احتفظ بقيمته الحالية. وإلا سيستخدم الكود `gemini-3.8-flash` كقيمة افتراضية.

لا تضع المفتاح في HTML أو JavaScript أو GitHub. بعد رفع التعديلات وعمل Commit/Push، سيبدأ Vercel النشر تلقائيًا إذا كان الربط مفعّلًا.

اختبر:

1. `https://YOUR-DOMAIN/api/status` — يعرض حالة إعداد المفتاح واسم الموديل، ولا يعرض المفتاح نفسه.
2. أرسل رسالة نصية عادية.
3. جرّب صورة صغيرة، ثم PDF صغير، ثم ملف TXT.
4. جرّب الميكروفون وقراءة الرد من متصفح يدعم Speech API.

## مهم بخصوص حماية المفتاح

مسار `/api/chat` متاح على نفس نطاق الموقع، ولا يوجد في هذه النسخة تسجيل دخول أو نظام حصص مستخدمين. لا تشارك رابط الموقع على نطاق واسع قبل إضافة حماية مناسبة أو تحديد معدل الطلبات، حتى لا يستهلك زوار آخرون حصة API الخاصة بك.

## توليد الصور بالذكاء الاصطناعي

لم يتم تفعيل توليد الصور أو إنشاء مسار مدفوع له في هذه النسخة. صفحة الأسعار الرسمية تعرض نماذج صور مستقلة مثل `gemini-3.1-flash-lite-image` بسعر منشور يقارب 0.0336 دولار لصورة 1K في الفئة القياسية، ولا تتوفر لها فئة مجانية في جدول الأسعار الحالي. لذلك يتطلب تشغيلها موافقة منفصلة أولًا.

## ملاحظات اختبار

تم فحص صياغة ملفات JavaScript محليًا. لا يمكن اعتبار اتصال Gemini أو صلاحية المفتاح أو دعم المتصفح للصوت ناجحًا قبل الاختبار من رابط Vercel الفعلي.
